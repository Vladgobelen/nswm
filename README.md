# nswm

Экспериментальная заготовка собственного оконного менеджера (Window Manager) на Rust для среды NSDE.

## Текущий статус

Проект находится в стадии разработки. На данный момент реализован только базовый сбор информации об окнах через X11 и Unix-сокет для связи с другими компонентами.

## Сборка и запуск

```bash
cargo build --release
./target/release/nswm
```
